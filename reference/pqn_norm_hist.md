# PQN coefficient histogram

A histogram of the PQN coefficients for all features

## Usage

``` r
pqn_norm_hist(...)
```

## Arguments

- ...:

  Additional slots and values passed to `struct_class`.

## Value

A ` pqn_norm_hist ` object. This object has no `output` slots. See
[`chart_plot`](https://rdrr.io/pkg/struct/man/chart_plot.html) in the
`struct` package to plot this chart object.

## Inheritance

A `pqn_norm_hist` object inherits the following `struct` classes:\
\
`[pqn_norm_hist]` \>\> `[chart]` \>\> `[struct_class]`

## Examples

``` r
M = pqn_norm_hist()

C = pqn_norm_hist()
```
