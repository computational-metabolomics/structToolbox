# RSD histogram

A histogram of the calculated RSD values.

## Usage

``` r
rsd_filter_hist(...)
```

## Arguments

- ...:

  Additional slots and values passed to `struct_class`.

## Value

A ` rsd_filter_hist ` object. This object has no `output` slots. See
[`chart_plot`](https://rdrr.io/pkg/struct/man/chart_plot.html) in the
`struct` package to plot this chart object.

## Inheritance

A `rsd_filter_hist` object inherits the following `struct` classes:\
\
`[rsd_filter_hist]` \>\> `[chart]` \>\> `[struct_class]`

## Examples

``` r
M = rsd_filter_hist()

C = rsd_filter_hist()
```
