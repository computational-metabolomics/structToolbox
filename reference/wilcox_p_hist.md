# Histogram of p values

A histogram of p values for the wilcoxon signed rank test

## Usage

``` r
wilcox_p_hist(...)
```

## Arguments

- ...:

  Additional slots and values passed to `struct_class`.

## Value

A ` wilcox_p_hist ` object. This object has no `output` slots. See
[`chart_plot`](https://rdrr.io/pkg/struct/man/chart_plot.html) in the
`struct` package to plot this chart object.

## Inheritance

A `wilcox_p_hist` object inherits the following `struct` classes:\
\
`[wilcox_p_hist]` \>\> `[chart]` \>\> `[struct_class]`

## Examples

``` r
M = wilcox_p_hist()

M = wilcox_p_hist()
```
